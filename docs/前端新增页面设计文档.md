## 1. PDF/Excel 导入页

### 1.1 路由

```
pages/import/import
```

### 1.2 后端接口

| 步骤 | 方法 | URL | 入参 | 返回 |
|------|------|-----|------|------|
| 上传课程表 | POST | `/api/v1/today/import` | `file`(PDF) + `user_id` + `import_type=course` | `{ import_id, total, items }` |
| 上传考试表 | POST | `/api/v1/today/import/excel` | `file`(.xlsx/.xls) + `user_id` | `{ import_id, total, items }` |
| 确认导入 | POST | `/api/v1/today/import/confirm` | `{ import_id }` | `{ import_id, saved_count }` |

### 1.3 页面流程

```
进入页面
  └─ 顶部两个 Tab：课程表 | 考试表
       ├─ 课程表 tab → 点击上传区域 → wx.chooseMessageFile(type="file", extension=["pdf"])
       └─ 考试表 tab → 点击上传区域 → wx.chooseMessageFile(type="file", extension=["xlsx","xls"])
              ↓
         显示文件名 + 大小 + "正在解析..."
              ↓
         预览列表（表格展示），每行可勾选
         ├─ 课程：课程名 | 教师 | 地点 | 星期 | 节次 | 周次
         └─ 考试：科目 | 日期 | 时间 | 地点
              ↓
         全选 / 取消全选 操作
              ↓
         底部固定「确认导入 N 项」按钮
              ↓
         成功 → Toast "已导入 N 项" → wx.switchTab 回今日模式
```

### 1.4 状态覆盖

| 状态 | 展示 |
|------|------|
| 初始 | 虚线框 + 云上传图标 + 提示文字「点击选择文件」+ 格式说明 |
| 上传中 | loading 动画 + "正在解析，请稍候..." |
| 解析为空 | 空状态插画 + "未识别到信息，请检查文件格式" + 重新选择按钮 |
| 解析失败 | 错误图标 + 错误信息 + 重试按钮 |
| 确认中 | 按钮 loading 态 |
| 确认成功 | Toast 提示 → 自动跳转 |
| 确认失败 | Toast 红色错误提示 |

### 1.5 数据格式

**课程表 items（API 返回）**：
```json
{
  "name": "高等数学",
  "teacher": "张老师",
  "location": "主教学楼 A201",
  "schedule": [
    { "weekday": 1, "start": 1, "end": 2, "weeks": "1-16周" }
  ]
}
```

**考试表 items（API 返回）**：
```json
{
  "subject": "高等数学",
  "exam_date": "2026-08-15",
  "start_time": "10:00",
  "end_time": "12:00",
  "location": "主教学楼 A101",
  "source": "excel_import"
}
```

### 1.6 后端补充说明

- 课程 PDF 解析基于 pdfplumber 表格提取，零 LLM 调用
- 考试 Excel 解析基于 openpyxl，按列名（课程名称 / 考试日期 / 考试地点）映射
- 预览数据存储在服务端内存（`_preview_store`），会话有效，确认后自动清除

## 2. 设置中心

### 2.1 路由

```
pages/settings/settings
```

### 2.2 后端接口

| 方法 | URL | 入参 | 用途 |
|------|-----|------|------|
| GET | `/api/v1/users/{user_id}` | — | 读取用户信息 |
| PUT | `/api/v1/users/{user_id}` | 任意字段(partial) | 更新个人信息 |
| DELETE | `/api/v1/users/{user_id}` | — | 注销账号 |
| GET | `/api/v1/memory/panel/{user_id}` | — | 读取记忆统计 |

### 2.3 页面结构

```
设置中心
├── 个人信息
│   ├── 姓名           [可编辑]
│   ├── 昵称           [可编辑]
│   ├── 学校           [可编辑]
│   ├── 学院           [可编辑]
│   ├── 专业           [可编辑]
│   ├── 年级           [可编辑]
│   └── 入学年份        [可编辑]
│
├── 长期记忆
│   ├── 记忆条目统计（共 N 条）
│   ├── 按类型分组：画像 N / 目标 N / 事实 N
│   └── 点击跳转 → /pages/memory/memory
│
├── 关于
│   └── 版本号 v2.1
│
├── 退出登录
│   └── 确认弹窗 → 清除 token → reLaunch 登录页
│
└── 注销账号
    └── 二次确认 → 删除账号 → reLaunch 登录页
```

### 2.4 交互细节

| 操作 | 方式 |
|------|------|
| 编辑个人信息 | 点击行 → `wx.showModal({ editable: true })` 弹出输入框 → 确认后 PUT |
| 退出登录 | 弹窗「确定退出？」→ `reLaunch("/pages/login/login")` |
| 注销账号 | 弹窗「注销后所有数据将被删除，不可恢复」→ DELETE 用户 → 清除 storage → reLaunch |

### 2.5 UserUpdate 可编辑字段（全部 optional）

```
name / nickname / school / college / major / grade / enroll_year
```

### 2.6 状态覆盖

| 状态 | 展示 |
|------|------|
| 加载中 | 骨架屏 |
| 保存中 | 按钮 loading |
| 保存成功 | Toast「已更新」 |
| 保存失败 | Toast 红色错误 |
| 注销中 | 全屏 loading「正在注销...」 |

## 3. 我的任务

### 3.1 路由

```
pages/tasks/tasks
```

### 3.2 后端接口

| 方法 | URL | 用途 |
|------|-----|------|
| GET | `/api/v1/todos?user_id=xxx&status=pending` | 待完成任务列表 |
| GET | `/api/v1/todos?user_id=xxx&status=done` | 已完成列表 |
| GET | `/api/v1/todos?user_id=xxx&status=archived` | 已归档列表 |
| POST | `/api/v1/todos?user_id=xxx` | 新建任务 `{ title, deadline?, source }` |
| PUT | `/api/v1/todos/{id}?user_id=xxx` | 编辑任务 `{ title?, status?, deadline? }` |
| DELETE | `/api/v1/todos/{id}?user_id=xxx` | 删除任务 |
| POST | `/api/v1/todos/{id}/toggle?user_id=xxx` | 状态切换 pending→done→archived |

### 3.3 页面结构

```
顶部 Tab 切换：待完成 | 已完成 | 已归档

任务列表
├── 每项显示
│   ├── 左侧 ○ 勾选圆（pending）/ ✓ 已完成（done）
│   ├── 标题
│   ├── 截止时间（如有）
│   ├── 来源标签：手动 / AI计划
│   └── 左滑露出删除按钮
│
├── 空状态
│   ├── 待完成 tab：「暂无待办任务」
│   ├── 已完成 tab：「还没有完成任何任务」
│   └── 已归档 tab：「归档为空」

右下角 FAB「+」→ 新建任务弹窗
```

### 3.4 交互细节

| 操作 | 行为 |
|------|------|
| 点击 ○ | toggle → 变 ✓（done）→ 从待完成列表移除，出现在已完成 |
| 点击 ✓ | toggle → 变 archived → 从已完成列表移除，出现在已归档 |
| 左滑 | 露出红色删除按钮 → 确认弹窗 → 彻底删除 |
| FAB「+」 | 弹窗输入标题 + 可选截止日期 → POST 创建 |
| 点击任务行 | 弹窗编辑标题/截止日期 → PUT 更新 |
| Tab 切换 | 切换 status 参数重新请求 |

### 3.5 数据格式

**API 返回单条 todo**：
```json
{
  "id": "uuid",
  "title": "完成高数课后练习",
  "status": "pending",
  "deadline": "2026-08-05",
  "source": "manual",
  "created_at": "2026-08-03T10:00:00"
}
```

**创建/编辑请求体**：
```json
{ "title": "新任务标题", "deadline": "2026-08-10", "source": "manual" }
```

### 3.6 状态覆盖

| 状态 | 展示 |
|------|------|
| 加载中 | 骨架屏 |
| 空列表 | 插画 + 文案（三个 Tab 各自不同） |
| 创建成功 | Toast「已添加」→ 刷新列表 |
| 网络错误 | 错误提示 + 重试 |
