## 二、今日模式 (Today) — PRD §6

### ✅ 已实现

| 功能点 | 实现位置 | 说明 |
|---|---|---|
| 时间轴日程展示 | `pages/schedule/schedule.wxml` | 课程+考试+待办 |

| 周视图日期行 | `pages/schedule/schedule.wxml:15-35` | 横向滚动日期 |

### ⚠️ 部分实现

| 功能点 | 现状 | 差距 | 改造工作量 |
|---|---|---|---|
| **日历周视图** | 仅显示一行 7 天日期 | 不能展开为月视图；不能点击日期切换当日事件 | 大（前端日历组件重构） |
| **时间轴事件颜色** | 统一样式 | 不同类型（课程/考试/待办/AI计划）应用不同颜色区分 | 小（前端 WXSS） |
| **AI 建议** | `schedule.wxml` 硬编码 | 应综合天气+课程+考试+待办+空闲时段由 AI 生成 | 中（后端 AI 调度 + 前端） |

### ❌ 未实现

| 功能点 | PRD 要求 | 改造工作量 |
|---|---|---|
| **PDF 导入课程表** | 上传 → OCR → AI 解析 → 用户确认 → 导入 | 大（OCR 库引入 + 解析 Pipeline + 确认 UI） |
| **PDF 导入考试表** | 同上 | 大 |
| **手动添加事件** | 新增/编辑/删除课程、考试、待办 | 大（后端 CRUD + 前端表单） |
| **事件类型完整覆盖** | 支持课程/考试/待办/AI计划/教师任务（后续）| 中 |
| **教师端同步** | 后续版本，不做 | — |

| 功能点 | 现状 | 差距 | 改造工作量 |
|---|---|---|---|
