# iCampus 教师端 — AI 协同教学平台开发计划

> **大赛赛道**: 教学赋能类（AI备课 + 学情分析 + 虚拟助教 + 作业智能批改）
> **大赛评审维度**: 作品创意 25%、技术创新 25%、实用性 20%、完整度 15%、用户体验 15%
> **文档日期**: 2026-08-06 | **开发周期**: 4 周（28 天）
> **原则**: 以大赛评审标准为导向，AI 是核心差异化，不做纯 CRUD

---

### 与大赛评审维度的对应

| 评审维度 | 权重 | 教师端如何体现 |
|---------|:--:|------|
| **作品创意** | 25% | AI 不仅是工具，是"协同教师"——备课、出题、批改、答疑都由 AI 协同完成，形成人机协作的教学闭环 |
| **技术创新** | 25% | 复用现有 LangGraph 多 Agent 架构 + 长期记忆系统，教师端 AI 与学生端 AI 共享同一记忆引擎，实现跨角色的知识流转 |
| **实用性** | 20% | 解决高校教师真实痛点：备课耗时、出题机械、批改重复、学情盲区。一套平台覆盖教学全流程 |
| **完整度** | 15% | 教师端(Web) + 学生端(小程序) + 共享AI后端 = 完整产品闭环 |
| **用户体验** | 15% | AI 生成内容可预览、可编辑、可确认后发布，"人在回路中"(Human-in-the-Loop) 的设计理念 |

## 二、四大 AI 能力详解

### 2.1 🤖 AI 备课助手（教学大纲 → 完整教案）

```
教师操作：
  输入：课程名称"高等数学" + 章节"第三章 微分中值定理"
  点击"生成教案"
       ↓
  ┌──────────────────────────────────────────────┐
  │ 📝 AI 生成的教案                              │
  │                                              │
  │ 【教学目标】                                  │
  │  1. 理解罗尔定理、拉格朗日中值定理的几何意义    │
  │  2. 掌握柯西中值定理及其推广                   │
  │  3. 能运用中值定理解决函数不等式证明问题        │
  │                                              │
  │ 【重点难点】                                  │
  │  重点：拉格朗日中值定理的条件与结论             │
  │  难点：构造函数应用中值定理                    │
  │                                              │
  │ 【教学过程】(45分钟)                          │
  │  导入(5min)：从物理"平均速度"引出中值定理      │
  │  讲授(25min)：三个定理逐个推导 + 几何演示      │
  │  练习(10min)：2道典型例题 + 学生板演          │
  │  总结(5min)：三个定理的关系对比                 │
  │                                              │
  │ 【课后思考题】                                │
  │  1. 拉格朗日中值定理在经济学中的应用？          │
  │  2. 如果取消"连续"条件，结论还成立吗？         │
  │                                              │
  │ [重新生成] [编辑] [保存为教案]                 │
  └──────────────────────────────────────────────┘
```

**技术实现**：
- `POST /api/v1/teacher/ai/generate-lesson-plan`
- 输入：`{ course_name, chapter, duration, style }`
- 复用 `LLMService.chat()`，约 2000 tokens/次
- 额外收益：教案中的思考题可一键转为作业

### 2.2 🤖 AI 智能出题（知识点 → 结构化试卷）

**同上版方案，保持不变**——只是增加"从备课教案中一键提取知识点出题"的快捷入口。

### 2.3 🤖 AI 学情深度分析（数据 → 洞察 → 预警）

```
教师操作：
  打开班级看板 → 点击"AI 学情分析"
       ↓
  ┌──────────────────────────────────────────────┐
  │ 📊 AI 学情深度报告                            │
  │                                              │
  │ 【整体画像】                                  │
  │  班级 32 人，本周 3 项作业，平均完成率 85%，   │
  │  较上周提升 5%。作业平均耗时 2.3 小时。       │
  │                                              │
  │ 【⚠️ 预警信号】(AI 自动识别)                   │
  │  🔴 张三 — 连续 3 次迟交，完成质量下降         │
  │     建议：单独沟通，了解是否遇到学业/生活困难   │
  │  🟡 李四 — 本周首次未交，此前全部按时          │
  │     建议：关注是否临时有事，可给予宽限          │
  │  🟢 王五 — 连续 2 周提前完成，质量优秀         │
  │     建议：可给予挑战性任务，避免"吃不饱"       │
  │                                              │
  │ 【知识薄弱点】(基于题目正确率)                  │
  │  "极限运算"类题目全班正确率仅 58%              │
  │  建议：下节课安排 15 分钟专题复习               │
  │                                              │
  │ 【趋势预测】                                  │
  │  按当前进度，预计 3 人期末可能不及格            │
  │  建议：安排期中摸底测试，提前干预               │
  └──────────────────────────────────────────────┘
```

**技术实现**：
- `POST /api/v1/teacher/ai/class-insight`
- 比简单摘要更进一步：LLM 接收结构化的个人完成序列数据，输出"预警等级 + 每个预警学生一段建议"
- 这是比赛评委最能直观感受 AI 价值的功能

### 2.4 🤖 AI 虚拟助教（学生提问 → AI 答疑 → 疑难转教师）

```
学生端操作流程：
  在待办详情页 → 点击"🤖 问 AI 助教"
       ↓
  ┌──────────────────────────────────────────────┐
  │ 💬 AI 助教                                   │
  │                                              │
  │ 学生："这道求极值的题，我算出来和答案不一样"    │
  │                                              │
  │ AI："你的思路可能是忽略了定义域限制。          │
  │      试试检查 f''''''(x) 的符号变化，           │
  │      极值点必须在临界点中寻找。"               │
  │                                              │
  │ 学生："还是不太明白..."                       │
  │                                              │
  │ AI："这个问题我无法完全解答，已转交给你的老师，  │
  │      老师回复后你会收到通知。"                  │
  │                                              │
  │ [继续提问]                                    │
  └──────────────────────────────────────────────┘

教师端看到：
  ┌──────────────────────────────────────────────┐
  │ 🚩 待处理的学生提问                            │
  │                                              │
  │ 张三 — 高等数学作业T3 (极值问题)               │
  │ 学生问："为什么我的答案和标准答案不一样？"       │
  │ AI 已回复一轮，学生追问                         │
  │                                              │
  │ [💬 回复学生] [标记已解决]                     │
  └──────────────────────────────────────────────┘
```

**技术实现**：
- 学生端小程序新页面 `pages/ai-ta/` — 针对某个作业的 AI 对话
- `POST /api/v1/class/ai-ta/ask` — 带作业上下文的 LLM 对话
- AI 自动判断置信度，低置信度自动 escalate 到教师端
- 教师端显示待处理提问列表 + 回复接口

> ⚠️ 此功能复杂度最高（需新建对话管理、escalation 路由、两端 UI），标记为 **第四周弹性任务**：前三周超前完成则追加，否则降级为先做"AI 预设常见问题自动回复"的简化版。

## 四、大赛演示脚本（10 分钟打动评委）

```
[0-2min]   场景引入
           "高校教师每周花费 8-12 小时在备课、出题、批改上。
            我们的 AI 协同教学平台，让这些时间减半。"

[2-4min]   🤖 AI 备课演示
            教师输入"高等数学·微分中值定理" → AI 30 秒生成完整教案
            → 教师微调 → 一键发布章节知识点

[4-6min]   🤖 AI 出题 + 班级联动演示
            从教案中提取知识点 → AI 生成 5 道题
            → 教师确认发布 → 切换小程序 → 学生待办列表出现新作业

[6-8min]   🤖 AI 虚拟助教演示
            学生在小程序对作业提问 → AI 实时解答
            → 复杂问题自动转教师 → 教师端看到待处理列表 → 回复

[8-10min]  🤖 AI 学情预警演示
            模拟 3 个学生不同的完成情况
            → 教师端 AI 学情报告：自动识别"张三连续3次迟交"
            → AI 建议"单独沟通"→ 薄弱知识点"极限运算"全班正确率仅58%
```

## 六、API 接口总表

### 认证 + 班级 + 作业/考试（同上版，略）

### 🤖 AI 能力（核心差异化）

| 方法 | 路径 | 功能 | 输入 | 输出 |
|------|------|------|------|------|
| POST | `/api/v1/teacher/ai/generate-lesson-plan` | AI 备课 | `{course, chapter, duration, style}` | `{objectives, key_points, process, homework_ideas}` |

| POST | `/api/v1/teacher/ai-ta/reply` | 教师回复学生 | `{question_id, reply}` | — |

## 七、不做清单

| 不做 | 原因 |
|------|------|
| AI 自动批改（OCR+打分） | 工程量大，1 个月做不完，可列为下一步 |
| AI 课程表解析 | PDF 解析 + OCR 链路长 |
| AI 个性化评语（每人一段） | 调用量不可控 |
| AI 学生画像（长期追踪） | 需要学期级数据积累 |
| 消息推送通知 | 微信模板消息审核周期长 |
