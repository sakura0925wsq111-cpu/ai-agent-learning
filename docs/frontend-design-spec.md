## 设计简述

iCampus v2.0 是一款面向中国大学生的 AI 校园助手微信小程序，覆盖**日常管理**、**成长决策**、**长期规划**三大场景。

### 设计理念

| 原则 | 说明 |
|------|------|
| **轻量克制** | 首页第一屏只展示当日最关键的 4 项指标 + 1 条 AI 建议，不堆砌信息 |
| **关怀感** | 吉祥物 + 时间段问候 + 考试倒计时 + 进度鼓励，让产品像朋友而非工具 |
| **渐进呈现** | 首页 → 今日模式 → 成长模式，三层递进，用户随时可深浅切换 |
| **一致性** | 全局统一色彩体系、事件类型色板、卡片圆角半径、字体层级 |

### 设计语言

- **色彩**: 主色蓝色 `#4A90D9`（校园/理性），辅以红/橙/绿功能色区分事件类型
- **圆角**: 大圆角卡片 `24rpx`（亲和），小圆角标签 `8rpx`（精致）
- **图标**: Emoji 为主（降低设计成本），关键位置使用定制 icon 图片
- **动效**: 简洁微交互（弹跳打勾、左滑删除、月历展开），不做花哨动画
- **字体**: 系统默认（苹方 / Microsoft YaHei），6 级字重层级覆盖所有场景

### 页面架构

```
启动页 → 登录/注册
           ↓
       ┌─ TabBar ──────────────────────────────┐
       │                                         │
       ▼         ▼         ▼         ▼          │
     首页    今日模式   AI助手   成长模式    我的  │
       │        │                    │          │
       │        ├─ PDF导入           ├─ 沙盒     │
       │        ├─ 事件管理          ├─ 规划     │
       │        └─ 待办列表          └─ 报告     │
       │                                         │
       └──────── 长期记忆（跨模式共享）──────────┘
```

## 6. 交互规范

### 6.1 手势

| 手势 | 场景 | 行为 |
|------|------|------|
| 下拉 | 列表页顶部 | 刷新数据 |
| 左滑 | 待办/事件列表项 | 露出删除按钮 |
| 长按 | 事件列表项 | 弹出编辑/删除菜单 |
| 点击 | 卡片/日期 | 导航/选中 |

### 6.2 反馈

| 时机 | 反馈 |
|------|------|
| 按钮点击 | hover-class 透明度变化 |
| 待办打勾 | 圆点弹跳 + 文字划线 + 绿色过渡 300ms |
| 待办删除 | 左滑 300ms 消失 + 下方项上移 |
| 删除确认 | 弹窗「确定删除？」 |
| 同步成功 | Toast「已同步 N 项任务到今日待办」 |
| 操作失败 | Toast + 红色图标 |

### 6.3 页面切换

- TabBar: wx.switchTab，无动画
- 子页面: wx.navigateTo，右滑进入 / 左滑返回
- 弹窗: 底部滑入 300ms + 蒙层渐现 200ms
