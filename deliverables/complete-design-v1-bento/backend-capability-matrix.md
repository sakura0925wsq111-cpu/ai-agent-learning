# 后端能力映射

设计原则：正式业务页只展示当前接口可返回的数据、AI 报告明确给出的字段，或现有前端已经实现的确定性计算。AI 推演与事实数据在界面上明确区分。

| 页面 | 当前能力 / 数据来源 | 允许的前端组合 | 明确不设计 |
| --- | --- | --- | --- |
| 启动与产品介绍 | 产品现有模块入口 | 今日、路径、成长报告的功能说明 | 社交、排名、奖励体系 |
| 登录与演示账号 | `POST /users/login`、注册流程、现有演示账号入口 | 学号/密码登录、演示账号、创建账号 | 短信、扫码、生物识别、第三方社交登录 |
| 今日智能工作台 | `GET /today/overview`、`/today/timeline`、`/today/calendar`、`/todos?status=all`、`POST /today/suggestion` | 今日到期任务完成度、近 7 天日历事件聚合 | 无来源的同比、能力自动增长、虚构逾期统计 |
| AI 成长教练 | 成长问答/流式问答、成长历史、报告、待办创建 | 读取执行状态与长期记忆，用户确认后创建待办 | 自动修改计划、替用户做决定 |
| 发展方向探索 | `GET /sandbox/paths`、`POST /sandbox/start` | 就业、考研、考公、转专业四条路径；选择 2–4 条推演 | 职位搜索、细分岗位推荐、匹配百分比 |
| 个人能力画像 | 成长报告、`GET /memory/panel/{user_id}` | 报告优势、挑战、记忆依据的可读摘要 | 雷达评分、目标能力分数、伪测评结论 |
| 路径详情 | 沙盘结果中的 `projections`、`key_uncertainties`、`decision_guide` | 时间阶段、适合点、挑战、不确定性和降低方式 | 薪资、录取率、就业概率、成功率 |
| 路径模拟对比 | `GET /sandbox/result/{session_id}` | `comparison_matrix` 的 1–10 分同轮相对对比、方案理由 | 将分值包装成概率或客观预测 |
| 行动计划 | `GET /today/progress`、`GET /todos`、`POST /todos/{id}/toggle` | 当前阶段、任务组、已完成/进行中/未开始 | 连续打卡天数、自动生成的成果增量 |
| 成长报告 | `GET /growth/report/{session_id}`、`GET /today/progress`、`POST /today/sync-plan` | 报告结论、阶段计划、同步状态、教练入口 | 月度趋势、上月对比、没有数据来源的能力曲线 |
| 数据导入中心 | `/today/import`、`/today/import/excel`、预览与确认接口 | 课程 PDF、考试 Excel/PDF；预览后确认写入 | 导入历史、云盘、相机 OCR、自动外部日历同步 |
| 数字成长档案 | 用户资料、成长仪表盘、成长报告、长期记忆、当前计划 | 档案摘要、报告列表、记忆类别、计划进度 | 优惠券、余额、徽章、排行、粉丝和游戏化奖励 |

## 数据展示约束

- 今日完成度只由“今天到期的待办”计算，分子与分母必须可追溯。
- 近 7 天活动来自日历中的课程、考试和待办事件聚合。
- 沙盘矩阵的 1–10 分仅用于同一次 AI 推演内比较，不表示成功概率。
- 能力画像是成长报告的结构化摘要，不包装成心理测评或标准化能力分数。
- AI 教练建议必须经过用户确认，才可写入待办或计划。
- 导入必须先预览；只有确认操作后才写入正式日程。
